## Copy-Paste Prompt

```text
Create an 8-10 second vertical 9:16 cinematic animated clip for Terminal Talk.

The clip should show the Terminal Talk mascot inside a futuristic software command center, coordinating multiple terminal sessions like a calm workflow commander.

Mascot design:
The mascot must stay very close to the Terminal Talk reference: simple orange pixel-art character, rectangular body/head, square black eyes, simple black smile, chunky blocky legs, flat pixel edges, friendly expression. Keep it clean and recognizable. Do not turn it into a human, animal, realistic robot, soldier, or different mascot. Avoid adding realistic arms, fingers, facial details, hair, armor, clothing, weapons, or extra limbs. If side blocks appear, keep them tiny and square like the original mascot ears/side tabs.

Environment:
A premium futuristic developer command center / software operations war room. Dark glass, glowing terminal monitors, cyan code panels, green status logs, subtle orange Terminal Talk rim lighting, holographic project dashboards, queue indicators, and multiple active terminal sessions around the mascot. The scene should feel like a high-end technology product advert, not a game combat scene.

Action:
The camera slowly pushes toward the mascot. Terminal panels on the left and right wake up and pulse as if frontend, backend, tests, docs, Claude Code, and Codex sessions are reporting in. Colored signal lines connect the panels to the mascot. The mascot gently bounces, turns slightly toward the active panels, and opens/closes its mouth as if speaking. The final moment should feel like the mascot has received the battlefield overview and is calmly relaying the decision.

Speech / narration intent:
The mascot is saying: "Terminal Talk online. Frontend, backend, tests, and docs are running. Codex and Claude are in the loop. Keep building. I will keep watch."

Important:
Do not generate any on-screen captions, subtitles, lower-third text, random words, labels, logos, watermarks, or misspelled text. Leave all text and captions out of the generated video. We will add exact captions and product labels later in editing.

Visual style:
Cinematic 3D animation with pixel-art mascot preserved. Smooth camera movement, subtle parallax, glowing terminal monitors, clean depth of field, polished SaaS/product launch feel. Sharp enough for marketing. Keep the mascot centered and visible for the whole clip.

Negative prompt:
No captions. No subtitles. No misspelled words. No random UI text as the focus. No weapons. No explosions. No soldiers. No military insignia. No real-world logos. No gore. No horror. No cluttered mascot face. No realistic human face. No redesigning the mascot. No changing mascot color away from Terminal Talk orange.
```
