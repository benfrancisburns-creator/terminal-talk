Faithful mascot dots — crispness + a clearer state system

Using the real mascot (full art), kept at the 14 px circle footprint, recoloured per session via the same data-palette scheme as the scrubber mascot. Two things to settle: (1) how to render it so it's crisp not hairy at this size, and (2) a state system where queued / auto-played / manually-played are obvious at a glance.

1 · Crispness — same mascot, different rendering

"Hairy" comes from shape-rendering="crispEdges" snapping the smile + 4 legs onto a fractional pixel grid at this size. Smooth anti-aliasing (geometricPrecision) lets the fine detail soften instead of fray. Compare each pair — left = crispEdges (today), right = smooth. Sizes 14 / 16 / 20 px.

2 · State system — which reads clearest?

At 14 px a tiny inner dot is nearly invisible, but brightness, a ring, or all-white all read instantly. Three candidate systems below. In every one, Manually-played = white mascot + session-colour ring, and Active (the clip playing right now) = pulsing white halo. They differ in how Queued vs Auto-played are shown.
