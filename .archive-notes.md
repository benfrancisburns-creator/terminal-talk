## How to undo any of this

- **Re-track a directory**: remove its line from `.gitignore`, `git add <dir>/`, commit
- **Restore a deleted branch**: `git checkout -b <name> archive/<name>`
- **Recover any file ever committed**: `git log --all --oneline -- <path>` then `git show <sha>:<path>`

Nothing in this cleanup is destructive. Everything is recoverable.
